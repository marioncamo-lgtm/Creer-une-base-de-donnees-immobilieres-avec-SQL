Qu’allez-vous apprendre dans ce projet ?
Vous allez apprendre à concevoir un schéma relationnel respectant la 3e forme normale (3NF). Vous mettrez en pratique la création de tables SQL, l’import de données CSV et la gestion de contraintes. Vous découvrirez aussi les concepts de dictionnaire de données et de conformité RGPD.

Ensuite, vous apprendrez à déployer une infrastructure Cloud professionnelle dans Databricks pour le stockage de la base de données. Tout au long de ce projet, nous vous accompagnerons dans l’utilisation de Databricks, un outil que vous pouvez utiliser gratuitement pendant votre formation. 

Enfin, vous écrirez des requêtes SQL avancées directement dans Databricks incluant des agrégations, des filtres complexes et des jointures multiples.

Cependant, si vous préférez utiliser une autre solution cloud comme AWS (S3 + RDS), Google BigQuery ou Snowflake, c'est possible. L'objectif principal est de disposer d'une base de données dans le cloud et de pouvoir y exécuter des requêtes. 

En quoi ces compétences sont-elles importantes pour votre carrière ?
Ces compétences sont essentielles pour tout poste d’analyste ou de développeur. 

La capacité à créer, modéliser et interroger une base de données hébergée sur le cloud est un pré-requis incontournable sur le marché de l’emploi.

Les recruteurs recherchent des profils capables de manipuler des données brutes pour en extraire des indicateurs exploitables.

La maîtrise de SQL, des modèles relationnels et des environnements cloud vous permettra de travailler efficacement dans des environnements data réels.

La capacité à justifier d’une méthodologie de travail rigoureuse, incluant l'usage responsable de l'intelligence artificielle, renforcera votre posture de consultant ou d'analyste.

Comment allez-vous procéder ?
Cours : Vous suivrez les cours liés à ce projet.

Mission : Créez la base de données : 

Dans cette première mission, vous analyserez les données pour extraire les variables clés. Vous mettrez à jour le schéma relationnel pour l’aligner aux nouvelles données, puis vous créerez la BDD.
Mission : 

Dans cette phase, vous vous exercerez à importer les données nettoyées dans la base de données que vous avez conçue, en respectant les types, contraintes et relations entre tables.

Vous rédigerez ensuite une série de requêtes SQL permettant d’analyser le marché immobilier : indicateurs clés, segmentations régionales, comparaisons, etc.

Enfin, vous préparerez une présentation structurée incluant vos choix de modélisation, votre méthodologie Cloud, vos requêtes SQL et leurs résultats, afin de démontrer la cohérence et l’efficacité de votre travail.

Vous terminerez en complétant la fiche d’autoévaluation qui servira de base de discussion avec votre mentor avant la soutenance.

À l’issue de ce projet, vous présenterez les livrables de la mission à un mentor évaluateur lors d’une soutenance.

Cela vous permettra de valider les compétences visées par ce projet.
